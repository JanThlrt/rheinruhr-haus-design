# RheinRuhr Haustechnik – AI Landing Page Challenge

Responsive und conversion-orientierte Landingpage für einen fiktiven SHK-Meisterbetrieb aus Düsseldorf.

Das Projekt entstand im Rahmen einer Praxis-Challenge mit dem Ziel, innerhalb eines begrenzten Zeitrahmens mithilfe moderner AI-Tools eine professionelle und skalierbare Landingpage zu entwickeln.

## Live Demo

https://rheinruhr-haus-design.lovable.app

## Ziel

Die Landingpage richtet sich an Eigenheimbesitzer in Düsseldorf und Umgebung, die sich für Heizungsmodernisierung, Wärmepumpen oder Badsanierung interessieren.

Hauptziel der Seite ist die Generierung qualifizierter Kontaktanfragen.

## Features

- Responsive Design für Desktop, Tablet und Smartphone
- Mobile Navigation
- Smooth-Scroll Anchor Navigation
- Conversion-orientierter Hero-Bereich
- Leistungsübersicht
- Vertrauens- und Vorteilssektion
- Wärmepumpen-Schwerpunkt
- Darstellung typischer Referenzprojekte
- FAQ-Accordion
- Kontaktformular mit Validierung und Feedback
- Click-to-Call-Funktion
- Hover- und Interaktionsanimationen
- Klare CTA-Führung

## AI-gestützter Workflow

Für Konzeption und Umsetzung wurden insbesondere **Claude** und **Lovable** eingesetzt.

### Claude

Claude wurde unter anderem verwendet für:

- Konzeption der Seitenstruktur
- Definition der Zielgruppe
- Conversion- und CTA-Konzept
- Formulierung und Überarbeitung der Inhalte
- Vorbereitung strukturierter Prompts für Lovable
- Bewertung und Optimierung einzelner UX-Entscheidungen

### Lovable

Lovable wurde für die schnelle technische und visuelle Umsetzung der Landingpage eingesetzt.

Der erste Entwurf wurde anschließend iterativ optimiert, insbesondere hinsichtlich:

- Mobile UX
- Navigation
- Formularvalidierung
- visueller Hierarchie
- CTA-Platzierung
- responsivem Verhalten
